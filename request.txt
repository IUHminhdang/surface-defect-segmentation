# 2. Giới thiệu đề tài

## 2.1. Bài toán

Trong kiểm tra chất lượng sản phẩm công nghiệp, các khuyết tật trên bề mặt thường có kích thước rất nhỏ, độ tương phản thấp và có thể gần giống với texture bình thường của bề mặt.

Nhóm sử dụng **KolektorSDD2**, một dataset cho industrial surface-defect segmentation. Dataset có **3,335 ảnh**, gồm **356 ảnh defective và 2,979 ảnh normal**, với pixel-level annotations; official split gồm 2,331 ảnh train và 1,004 ảnh test.

Bài toán của nhóm:

```
Input image
     ↓
Segmentation model
     ↓
Pixel-level defect mask
```

Ví dụ:

```
             Input
       ┌───────────────┐
       │               │
       │       ───     │
       │      defect   │
       │               │
       └───────────────┘
               ↓
              Model
               ↓
             Mask
       ┌───────────────┐
       │               │
       │       ███     │
       │      █████    │
       │               │
       └───────────────┘
```

# 3. Vấn đề nghiên cứu

Nhóm tập trung vào 3 vấn đề:

### Problem 1 — Tiny defect

Khi encoder liên tục downsample:

```
Image
 ↓
1/2
 ↓
1/4
 ↓
1/8
 ↓
1/16
 ↓
1/32
```

defect quá nhỏ có thể mất thông tin.

→ **Multi-Scale Feature Fusion**

---

### Problem 2 — Irrelevant features

Skip connection truyền rất nhiều thông tin từ encoder sang decoder, trong đó có cả background/texture không liên quan.

→ **Attention Gate**

```
Encoder feature
      ↓
Attention Gate
      ↓
Filtered feature
      ↓
Decoder
```

---

### Problem 3 — Boundary

Defect có thể rất nhỏ và boundary khó xác định.

→ **Boundary-Aware Loss**

$L=L_{BCE}+L_{Dice}+\lambda L_{Boundary}$

# 12. Image-level evaluation

Từ segmentation mask:

```
Predicted defect pixels
          ↓
    area > threshold?
       ↙       ↘
     Yes        No
      ↓          ↓
   Defect      Normal
```

Tính:

- Image Precision
- Image Recall
- Image F1
- Normal-image False Positive Rate

Đặc biệt:

FPRnormal=#normal images predicted as defective#normal imagesFPR_{normal} = \frac{\#normal\ images\ predicted\ as\ defective} {\#normal\ images}

Điều này rất phù hợp với industrial inspection.
